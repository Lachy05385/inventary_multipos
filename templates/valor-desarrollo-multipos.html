⚙️ 2. Consideraciones técnicas — por qué es moderno

Arquitectura actual Multi-POS

  • FastAPI + Python moderno asíncrono: maneja múltiples sesiones concurrentes sin bloquearse. Cada caja es una sesión independiente con token JWT.
  • API-REST stateless + OpenAPI 3.1: documentado en /docs y /openapi.json. Cualquier frontend (web, Android, PWA) consume lo mismo.
  • Roles reales: admin warehouse_manager cashier con permisos por endpoint.
  • Multi-POS nativo: /pos/locations + /warehouse/transfer + /warehouse/stock/consolidated. Almacén central reparte a tiendas y consolida existencias.
  • Ventas flexibles: POST /pos/{id}/sale y batch-sale con cash_amount + transfer_amount + change_given — ideal para efectivo + Transfermóvil.
  • Control de caja auditable: retiros con motivo, solicitudes y autorización, resumen por caja.
